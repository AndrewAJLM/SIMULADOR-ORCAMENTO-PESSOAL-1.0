# SIMULADOR-OR-AMENTO-PESSOAL-1.0
É uma calculadora de orçamento pessoal, onde você insere dados como, salário, gastos e reserva atual.


Línguagem usadas:

-HTML;
-CSS;
-JAVASCRIPT.



<img width="999" height="599" alt="Captura de tela 2026-10-29 210000" src="https://github.com/user-attachments/assets/bc01e088-0d36-427c-b02e-d28fa9a7f441" />



Além dos gastos comuns, você também pode customizar adicionando seus próprios gastos!

Clique no botão "+" na parte inferior do app, digite o nome que quer dar ao novo gasto e aperte "ENTER" para salvar. Em seguida, basta adicionar o valor que corresponder ao seu novo gasto mensal.
